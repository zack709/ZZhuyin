### 2.3 4-Slot → 16-bit 編碼規則（`FUN_7ff4085efc0`）

## 3. 注音組字與覆蓋狀態機（核心演算法）

由 `FUN_7ff4082ce50` → `FUN_7ff4083467c` → `FUN_7ff40833358` → `FUN_7ff4083304c` 實作（Evidence: `ev_1bf916d9d11073ae1a7726e03f5a66a6104c66a78505f733a71d37df179ac906`、`ev_8bc0a1b1e2f373122c412dbc45e23e6766fed7d33466fa8809a560a5be04bafb`、`ev_0b8d901fe48b9fbc11fc20364116e35c5b7239d391029b4f2cf5e16b999c6765`、`ev_21073b38395a568a4f1c002f6c4bea9455189d03697787deea8a980789b02b45`）：

### 3.1 同類音覆蓋與無序輸入規則（`FUN_7ff4083304c`）
每次輸入新的注音鍵時，系統將該鍵追加至原始按鍵序列 `raw_keys`，並重新執行正規化：
1. 將所有已輸入按鍵映射為 4-tuple `(slot, seq_idx, raw_key, bopomofo_wchar)`，其中 `slot ∈ {0, 1, 2, 3}`。
2. 以 `(slot, seq_idx)` 穩定排序（`FUN_7ff40835614`）。
3. 取出最大槽位 `max_slot`，配置長度為 `max_slot + 1` 的顯示陣列（初值 `U+3000`）與正規化鍵列（初值 `` ` ``）。
4. 依序執行 `display[slot] = bopomofo_wchar`、`normalized_keys[slot] = raw_key`：
   - **同類音覆蓋**：同一 `slot` 若出現多個按鍵，因按 `seq_idx` 遞增寫入，**後打的必定覆蓋先打的**（例如：`ㄅ` → `ㄆ` 變成 `ㄆ`；`ㄆㄧㄚ` 再打 `ㄨ` 變成 `ㄆㄨㄚ`）。
   - **支援亂序拼字**：即使先打韻母 `ㄚ`（slot 2）再打聲母 `ㄅ`（slot 0），顯示與正規化鍵列都會自動重排為正規順序 `ㄅㄚ`。
5. 清除 `normalized_keys` 中未填槽位的佔位符，保存為新的 `raw_keys`（最多 4 鍵，按 `Initial → Medial → Final → Tone` 排序）。

### 3.2 四聲觸發查字、不合法組合與自動上字規則
- **觸發查字條件**（`FUN_7ff4082ce50` + `FUN_7ff4083467c` + `FUN_7ff408268f8`，Evidence: `ev_c122f2d87c826cad1ec841352d1b6fa083fe310120acb48b82a90b9c4ba7ac22`）：

- **`IDLE`**：無組字、無候選視窗。
- **`COMPOSING`**：讀音緩衝區有 1～3 個注音符號（聲／介／韻），尚未完成聲調。
